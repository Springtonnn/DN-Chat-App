# DN Chat App

Public Chat Web Application
เว็บแอปพลิเคชันสำหรับการสนทนาแบบ Real-Time ระหว่างผู้ใช้งานหลายคน

ระบบสามารถ

สมัครและเข้าสู่ระบบด้วยชื่อผู้ใช้และรหัสผ่าน
ส่งข้อความแบบ Real-Time
แสดงประวัติข้อความ
ส่งรูปภาพในแชท
ออกจากระบบและกลับเข้าสู่ระบบได้

## วิธีรัน

```bash
npm install
npm start
```

จากนั้นเปิด `http://localhost:3000`

> ไม่ได้รวม `node_modules` ใน ZIP เพื่อไม่ให้ native module ของ `better-sqlite3` ติด platform เดิมมาด้วย
