# DN Chat App – Updated

ปรับตามไฟล์ออกแบบ PDF และคำขอเพิ่มเติม:

- Logout เลื่อนกลับขึ้นหน้าล็อกอินด้วยความเร็วเดียวกับ animation ตอน Login
- ตอนกด Logout ไม่ล้างค่ารหัสผ่านในช่อง Login
- เพิ่มข้อความกลางแชทสีน้ำตาลเฉพาะตอนสร้างบัญชีใหม่ครั้งแรก: `ชื่อผู้ใช้ เข้าร่วมแชทสาธารณะ`
- เพิ่มรายชื่อผู้ใช้ออนไลน์ผ่าน Socket.IO
- จำกัดข้อความที่แสดง/เก็บไว้ในพื้นที่แชทไม่เกิน 30 ข้อความล่าสุด เพื่อช่วยลด DOM และ memory usage
- รองรับไฟล์แนบสูงสุด 20 MB ต่อไฟล์: PDF / PNG / JPG / JPEG / GIF / WebP / AVIF / TXT / CSV / ZIP / DOC / DOCX / XLSX / PPTX
- GIF/AVIF แบบเคลื่อนไหวเล่นได้ตามความสามารถของ browser และไฟล์เอกสารจะแสดงเป็นการ์ดดาวน์โหลด/เปิดไฟล์
- ข้อความใหม่ slide เข้าจากด้านข้างแบบเร็ว
- เพิ่มเสียง "ป็อก" เบา ๆ เมื่อมีข้อความใหม่ โดยสร้างเสียงจาก Web Audio API ไม่ต้องมีไฟล์เสียงเพิ่ม

## วิธีรัน

```bash
npm install
npm start
```

จากนั้นเปิด `http://localhost:3000`

> ไม่ได้รวม `node_modules` ใน ZIP เพื่อไม่ให้ native module ของ `better-sqlite3` ติด platform เดิมมาด้วย
